# Hello World with AGENT Development

Tài liệu cho sinh viên về cách xây dựng và vận hành một agent đơn giản (ví dụ: agent hoàn tiền, Python + Claude API).

- `refund-agent/`: code ví dụ đi kèm, xem [docs/index.md](docs/index.md)

```powershell

uv run mkdocs build      # xuất site tĩnh ra site/
```
